Corollary 3.1 Corollary 1.4: Cone-Manifolds with Cone Angles \(\le 2\pi \)
✓
#

Uses

  • AlexandrovConsequences.cone_manifold_entropy_degree_bound

For a compact orientable \(N\)-cone-manifold \(Z\) (\(N \ge 3\)) with cone angles \(\le 2\pi \) and \(K_{\mathrm{reg}} \ge -1\) (so \(0 \le h(\overline{Z}) \le N - 1\)), every continuous map \(f : Z \to Y\) satisfies \(|\deg (f)|\, h(\widetilde{Y})^N \mathcal{H}^N(Y) \le (N-1)^N \mathcal{H}^N(Z)\).

Proof ▶

Direct application of upper_entropy_bound_volume_inequality with \(h_{\mathrm{upper}} = N - 1\).

Corollary 3.2 Corollary 1.5: Hyperbolic Manifolds with Locally Convex Boundary
✓
#

Uses

  • Lemma 1.6

Lean declarations

  • AlexandrovConsequences.convex_manifold_boundary_volume_bound

For a compact oriented \(N\)-manifold \(Z\) (\(N \ge 3\)) with locally convex boundary and \(\mathrm{sec} \ge -1\) mapped with relative degree \(k \in \mathbb {Z}\) to a hyperbolic \(N\)-manifold \(Y_{\mathrm{geod}}\) with totally geodesic boundary, Perelman doubling \(DZ \to DY_{\mathrm{geod}}\) yields \(|k|\, \operatorname {Vol}(Y_{\mathrm{geod}}) \le \operatorname {Vol}(Z)\).

Proof ▶

Since \(N \ge 3\), \(h_0 = N - 1 {\gt} 0\); apply metric_doubling_volume_degree_bound.

Corollary 3.3 Corollary 1.6: Geometrically Finite Hyperbolic 3-Manifold Convex Cores

#

Uses

  • Corollary 3.2

For convex cores \(C_M \to C_{M_g}\) of geometrically finite hyperbolic \(3\)-manifolds (\(N = 3, h_0 = 2\)) of relative degree \(k\), both the doubled core and smooth \(r\)-neighborhood approximation limit yield \(|k|\, \operatorname {Vol}(C_{M_g}) \le \operatorname {Vol}(C_M)\).

Proof ▶

Specialize Corollary 1.5 to \(N = 3\) and pass to the limit \(\operatorname {Vol}(Z_{r_i}) \to \operatorname {Vol}(C_M)\) via ge_of_tendsto.

Corollary 3.4 Corollary 1.7: Unified Degree and Weil–Petersson Core Volume Bound
✓
#

Uses

  • Corollary 3.3

Lean declarations

  • AlexandrovConsequences.unified_degree_weil_petersson_core_bound

Combining Corollary 1.6 for \(f \circ h : M'_{\mathrm{geod}} \to M_{\mathrm{geod}}\) (\(|\deg (h)| = 1\)) with the Bridgeman–Brock–Bromberg comparison gives

\[ |k|\, \operatorname {Vol}(C_{M_{\mathrm{geod}}}) + A(\partial Z')\, d_{\mathrm{WP}}(\partial _c M', \partial _c M'_{\mathrm{geod}}) - \delta \le \operatorname {Vol}(C_{M'}). \]
Proof ▶

Degree multiplicativity gives \(|\deg (f \circ h)| = |k|\), and adding the Weil–Petersson comparison \(\operatorname {Vol}(C_{M'}) - \operatorname {Vol}(C_{M'_{\mathrm{geod}}}) \ge A(\partial Z')\, d_{\mathrm{WP}} - \delta \) completes the proof.

Definition 3.5 Infimal Convex-Hyperbolic Volume
✓
#

  • AlexandrovConsequences.infimalConvexHyperbolicVolume

For a parameterized family \(S\) of convex hyperbolic metrics on the compactified end-periodic mapping torus \(\overline{M}_\phi \), define \(\underline{\operatorname {Vol}}(\overline{M}_\phi ) := \inf _{g \in S} \operatorname {Vol}(\overline{M}_\phi , g)\).

On a nonempty family \(S\) of convex hyperbolic metrics on \(\overline{M}_\phi \), Corollary 1.5 holds uniformly, giving \(|k|\, \operatorname {Vol}(Y) \le \underline{\operatorname {Vol}}(\overline{M}_\phi )\), and combining with \(\underline{\operatorname {Vol}}(\overline{M}_\phi ) \le V_{\mathrm{oct}}\, \tau (\phi )\) (\(V_{\mathrm{oct}} {\gt} 0\)) yields

\[ \frac{|k|}{V_{\mathrm{oct}}}\, \operatorname {Vol}(Y) \le \tau (\phi ). \]
Proof ▶

Apply le_csInf over the nonempty image vol ” S, then divide by \(V_{\mathrm{oct}} {\gt} 0\).
