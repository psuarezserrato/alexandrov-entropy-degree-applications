Lemma 5.1 Reviron Entropy Lower-Semicontinuity Product Limit

#

  • AlexandrovConsequences.limit_entropy_pow_le_of_eventually_add_eps

If \(\operatorname {Vol}(M_i) \to V_X {\gt} 0\), \(h(\widetilde{M}_i)^N \operatorname {Vol}(M_i) \to L\), and \(\forall \varepsilon {\gt} 0, \forall ^\infty i,\, h_{\mathrm{lim}} \le h(\widetilde{M}_i) + \varepsilon \), then \(h_{\mathrm{lim}}^N V_X \le L\).

Proof ▶

Since \(V_X {\gt} 0\), \(h(\widetilde{M}_i)^N \to L / V_X\). For each \(\varepsilon {\gt} 0\), eventually \((\max (h_{\mathrm{lim}} - \varepsilon , 0))^N \le h(\widetilde{M}_i)^N\), so taking \(i \to \infty \) and then \(\varepsilon \to 0^+\) yields \(h_{\mathrm{lim}}^N \le L / V_X\).

Corollary 5.2 Corollary 1.11: Gromov–Hausdorff Stability of Hyperbolic Volume

If closed \(N\)-manifolds \((M_i)\) (\(N \ge 3\), \(\mathrm{sec} \ge -1\)) converge in Gromov–Hausdorff distance to \((X, \mathsf{d})\) with \(\operatorname {Vol}(M_i) \to k\, \operatorname {Vol}(Y)\) (\(k \ge 1\)) and Perelman stability transfers \(|\deg | = \mathrm{index} = k\), then \(\operatorname {Vol}(X) = k\, \operatorname {Vol}(Y)\), \(h(\widetilde{X}) = N - 1\), \(\mathcal{S}_X = \emptyset \), and \(X\) is globally isometric to the smooth degree-\(k\) hyperbolic cover of \(Y\) (\(Y\) itself when \(k = 1\)).

Proof ▶

Uniqueness of Hausdorff limits equates \(\operatorname {Vol}(X) = k\, \operatorname {Vol}(Y)\); Perelman stability transfers degree/index \(k\); and Theorem 1.1 squeezes \(h(\widetilde{X}) = N - 1\), triggering unrescaled rigidity.

For any closed orientable negatively curved locally symmetric \(N\)-manifold \(Y\) (\(N \ge 3\)), if \(h(\widetilde{M}_i)^N \operatorname {Vol}(M_i) \to k\, h(\widetilde{Y})^N \operatorname {Vol}(Y)\) (\(k \ge 1\)), \(\operatorname {Vol}(M_i) \to \operatorname {Vol}(X) {\gt} 0\), and Reviron’s entropy lower-semicontinuity holds, then \(h(\widetilde{X})^N \operatorname {Vol}(X) = k\, h(\widetilde{Y})^N \operatorname {Vol}(Y)\), \(h(\widetilde{X}) {\gt} 0\), \(\mathcal{S}_X = \emptyset \), and \((X, (h(\widetilde{X})/h(\widetilde{Y}))\mathsf{d}_X)\) is globally isometric to the smooth degree-\(k\) cover \(\widehat{Y}\).

Proof ▶

Combine Lemma 5.1 (\(\le \)) with Theorem 1.1 (\(\ge \)) to obtain equality, extract \(h(\widetilde{X}) {\gt} 0\), and apply Theorem 1.1 equality rigidity.
